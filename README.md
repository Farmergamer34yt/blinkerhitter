# 🌿 Penjamin Simulator

A small, terminal-based Python game about hitting the penjamin, earning money, and buying upgrades to hit the penjamin even more efficiently.

This project started as a simple experiment with Python loops, conditionals, and random numbers. It gradually evolved into an incremental game with a currency system, purchasable upgrades, and plans for future features.

Is it a groundbreaking piece of software? Absolutely not. Does it work? That's what matters.

## 🎮 Features

* **Randomized Rounds:** Each round randomly determines your maximum hits before greening out.
* **Currency System:** Earn money based on the number of hits you complete.
* **Upgrade Shop:** Spend your hard-earned money on upgrades to improve your performance.
* **Better Battery:** Increases your maximum hits by 5 per purchase.
* **Money Multiplier:** Doubles the money earned per hit with each purchase.
* **Lucky Charm:** Increases your maximum hits by 10 per purchase.
* **Replayability:** Keep playing rounds and purchasing upgrades for as long as you want.

## 🛠️ Built With

* **Python 3**
* Python's built-in `random` module

No external libraries are required.

## 🚀 Getting Started

### Prerequisites

Install Python 3 if you don't already have it.

### Running the Game

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/penjamin-simulator.git
   ```

2. Navigate into the project directory:

   ```bash
   cd penjamin-simulator
   ```

3. Run the Python script:

   ```bash
   python main.py
   ```

   Depending on your system, you may need to use `python3 main.py` instead.

*Replace `YOUR-USERNAME` with your GitHub username and `main.py` with your actual Python filename if it's different.*
